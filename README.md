# KoddoSchool — schone start

Deze branch is een volledig nieuwe, zelfstandige startpagina. Oude CSS, JavaScript en afbeeldingen uit eerdere prototypes worden niet geladen.

- `index.html`: semantische startpagina
- `style.css`: alle nieuwe vormgeving en responsive gedrag
- `script.js`: mobiele navigatie en voorlopige knopmeldingen

De login- en leerjaaracties zijn nog prototypes en authenticatie is nog niet aangesloten.
